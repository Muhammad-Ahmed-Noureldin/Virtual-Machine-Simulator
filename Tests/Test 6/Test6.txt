; ------------------------------------------------------------
; Test6.txt : Greatest Common Divisor (Euclid by subtraction)
; ------------------------------------------------------------
; WHAT THIS PROGRAM DOES (load it at address 00):
;  Computes GCD(48, 18). It prints both inputs first, then runs
;  the subtraction form of Euclid's algorithm:
;     while a != b:  if a > b then a = a - b else b = b - a
;  There is no subtract or greater-than instruction, so:
;   - subtraction is done by adding the two's complement
;     (NOT via XOR with FF, then + 1),
;   - a == b is detected when a - b equals zero,
;   - a > b is detected by testing the sign bit (AND 80) of
;     a - b: sign bit clear means a > b.
;  When the loop ends, a holds the GCD and it is printed.
;  Inputs must stay below 128 for the sign test to be valid.
;
;  Register usage:
;   R0 = 0 (zero register)  R1 = a   R2 = b   R3 = FF
;   R4 = 01   R5 = 80 (sign mask)   R6 = negated value
;   R7 = difference   R8 = sign bit of the difference
; ------------------------------------------------------------

2000   ; R0 = 0
2130   ; R1 = 30 (48)
2212   ; R2 = 12 (18)
23FF   ; R3 = FF
2401   ; R4 = 01
2580   ; R5 = 80
31FF   ; print a (input)
32FF   ; print b (input)
9623   ; LOOP: R6 = NOT b
5664   ; R6 = -b
5716   ; R7 = a - b
B72A   ; if a - b == 0 jump to DONE (2A)
8875   ; R8 = sign bit of (a - b)
B826   ; if sign clear (a > b) jump to AGTB (26)
9613   ; R6 = NOT a
5664   ; R6 = -a
5726   ; R7 = b - a
4072   ; b = R7
B010   ; jump back to LOOP (10)
4071   ; AGTB: a = R7
B010   ; jump back to LOOP (10)
31FF   ; DONE: print a (the GCD)
C000   ; halt

;  Decimal: 48 18 6
;  Hex:     30 12 06
;  Meaning: the two inputs, then GCD(48, 18) = 6.
;  Trace of (a, b): (48,18) -> (30,18) -> (12,18) -> (12,6) -> (6,6)
; ------------------------------------------------------------
